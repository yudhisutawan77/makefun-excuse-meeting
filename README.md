- **Bounty:** [The Funniest Excuse for Skipping a Meeting](https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163)
- **Prize pool:** $10 (split across the top 10)
- **Deadline:** 27 November 2026, 00:00 WITA

## Entry

> Can't join — I'm in a support group for people who attend too many meetings. It meets at the same time. Every week.

## How it works

`main.py` writes the single-line excuse to the output the grader expects,
resolving the location in this order: `ENTRY_OUT` (file or directory),
`MAKEFUN_OUTPUT_DIR`, `/output/entry.txt`, and the working directory as a
last resort. The text is written with no trailing newline.

Run it:

```sh
python3 main.py
```
